Diskrete Verteilungen: Binomial, Hypergeometrisch, Poisson

Die Antwort auf die wichtigste Qualitätsfrage überhaupt: „Wie viele defekte Stücke stecken in dieser Stichprobe?" — drei Verteilungen, drei Zieh-Szenarien, ein gemeinsames d/p/q/r-Schema aus L0003 im Ernstfall.

Warum diese Lektion

In L0003 hast du das Gerüst gebaut: Zufallsvariable, diskret vs. stetig, f(x) vs. F(x) und das d/p/q/r-Schema. Jetzt kommt das erste echte Fleisch — und es ist genau das, was die Annahmestichprobenprüfung (ISO 2859, ein Kern von KM7) in R braucht. Die Grundfrage überall gleich: „Ich prüfe n Stücke aus einer Lieferung. Wie groß ist die Wahrscheinlichkeit, x defekte zu finden?" Je nachdem, wie die Stücke zustande kommen, antwortet eine andere diskrete Verteilung.

Die eine Idee

Drei diskrete Verteilungen, drei „Zieh-Geschichten": Binomial = n unabhängige Würfe mit konstanter Erfolgswahrscheinlichkeit p (mit Zurücklegen). Hypergeometrisch = Ziehen ohne Zurücklegen aus einem endlichen Los (die echte Annahmeprüfung). Poisson = seltene Ereignisse pro Zeit/Fläche, gezählt statt geprüft. Alle drei nutzen exakt dieselben vier R-Funktionen: d, p, q, r.

1. Binomialverteilung — „n unabhängige Versuche"

Ein einzelnes Stück ist entweder i.O. oder defekt — das ist ein Bernoulli-Experiment. Prüfst du n Stücke, die alle unabhängig mit derselben Wahrscheinlichkeit p defekt sind, ist die Zahl der Defekten binomialverteilt: X ~ Bin(n, p).

WerteBeispiel (Qualität)
nAnzahl Versuche100 geprüfte Stücke
pErfolgswsk je Versuchp = 0,02 (2 % defekt)
XAnzahl ErfolgeAnzahl defekter Stücke

Die Wahrscheinlichkeitsfunktion — zähl aus, auf wie viele Arten man x Erfolge auf n Plätze verteilen kann:

f(x) = C(n, x) · pˣ · (1−p)ⁿ⁻ˣ

mit C(n,x) = n! / (x! · (n−x)!) — in R: choose(n, x). Der Erwartungswert (kommt in Track 2 formal, hier schon die Regel): E(X) = n·p.

R-Praxis — Annahmeprüfung: n = 100 Stück, p = 0,02

# d = f(x): Wahrscheinlichkeit fuer GENAU x defekte
dbinom(0, size = 100, prob = 0.02)   # P(0 defekt) ≈ 0,133
dbinom(1, size = 100, prob = 0.02)   # P(1 defekt) ≈ 0,271
dbinom(2, size = 100, prob = 0.02)   # P(2 defekt) ≈ 0,273

# p = F(x): kumuliert — BIS zueglich x defekte
pbinom(2, size = 100, prob = 0.02)   # P(X ≤ 2) ≈ 0,677

# q = Quantil: kleinste Zahl, bis zu der ≥ 95 % der Faelle liegen
qbinom(0.95, size = 100, prob = 0.02) # 5 → P(X ≤ 5) = 0,985 ≥ 0,95 (P(X ≤ 4) = 0,949)

# Erwartungswert: im Mittel n·p = 2 defekte
100 * 0.02                           # 2
Output 
[1] 0.1326196
[1] 0.2706522
[1] 0.2734139
[1] 0.6766856
[1] 5
[1] 2

Gegenprobe von Hand: dbinom(0,100,0.02) = 0,98¹⁰⁰ — alle 100 Stücke müssen gut sein, Wahrscheinlichkeit je Stück 0,98. Das Komplement „mindestens 1 defekt" ist 1 − 0,133 = 0,867.

Wichtige Voraussetzung

Binomial setzt konstantes p und Unabhängigkeit voraus — gedanklich „mit Zurücklegen": Jedes Stück hat dieselbe Fehlerchance, egal was vorher kam. Bei einem endlichen Los, das man Stück für Stück ohne Zurücklegen zieht, verändert sich die Defektquote mit jedem Zug — genau dafür gibt es die Hypergeometrische Verteilung.

Verständnis
Ein Betrieb prüft n Stück aus einer laufenden Produktion (praktisch unendliche Grundgesamtheit). Welche Verteilung für die Anzahl der Defekten?
  • Hypergeometrisch, ohne Zurücklegen
  • Binomial, mit konstantem p
  • Poisson, über die Zeit
  • Stetig, wie die Dichte
Richtig. Aus praktisch unendlicher Produktion ändert das Prüfen das p nicht — Unabhängigkeit, konstantes p, also Binomial.
Falsch. Bei laufender Produktion (kein endliches Los) bleibt die Defektquote konstant → Binomial. Hypergeometrisch wäre es bei einem endlichen Los ohne Zurücklegen.
R-Praxis
Was berechnet pbinom(2, 100, 0.02)?
  • P(X = 2) — genau zwei defekte
  • P(X ≥ 2) — mindestens zwei defekte
  • P(X ≤ 2) — höchstens zwei defekte
  • Den Erwartungswert 2
Richtig. p = Verteilungsfunktion F(x) = P(X ≤ x). Genau x liefert dbinom, mindestens x braucht lower.tail = FALSE.
Falsch. p-Präfix = kumuliert = „höchstens x" (P(X ≤ x)). Für „genau 2" wäre es dbinom.

2. Hypergeometrische Verteilung — „Ziehen ohne Zurücklegen"

Jetzt die exakte Annahmeprüfungssituation (ISO 2859): Eine Lieferung von N Stücken liegt, M davon sind defekt. In der Praxis ist M unbekannt — genau das soll die Prüfung ja schätzen; für die Rechnung setzt man einen angenommenen Wert an (hier M = 10). Du ziehst n Stück ohne Zurücklegen — jedes gezogene defekte Stück reduziert die verbliebene Defektquote. Drei Parameter:

ParameterBedeutungBeispiel
NLosgröße (Grundgesamtheit)200 Stück im Los
MDefekte im Los10 defekt
nStichprobenumfang20 gezogen

f(x) = C(M, x) · C(N−M, n−x) / C(N, n)

Zähler: x der M defekten und n−x der N−M guten Stücke wählen. Nenner: alle Möglichkeiten, n aus N zu ziehen. In R heißt die Reihenfolge anders als man denkt:

# dhyper(x, m, n, k) mit:  m = M (defekte im Los),
#                          n = N-M (gute im Los),
#                          k = n (gezogene Stichprobe)
dhyper(0, m = 10, n = 190, k = 20)  # P(0 defekt) ≈ 0,340
dhyper(1, m = 10, n = 190, k = 20)  # P(1 defekt) ≈ 0,397
dhyper(2, m = 10, n = 190, k = 20)  # P(2 defekt) ≈ 0,198
Output 
[1] 0.3397744
[1] 0.3973969
[1] 0.1975432

Die häufigste Antwort ist „1 defekt" — weil 10 von 200 defekt sind und die Stichprobe 20 beträgt (Erwartungswert n·M/N = 20·10/200 = 1).

Wann Binomial statt Hypergeometrisch?

Ist die Stichprobe klein gegen das Los (Faustregel n/N ≤ 5 %), ändert das Ziehen die Defektquote kaum — die Hypergeometrische und die Binomialverteilung liefern fast gleiche Werte. Dann darf man mit der einfacheren Binomialformel rechnen. Beispiel N=2000, M=100 (5 %), n=20: dhyper(0,100,1900,20) ≈ 0,358 vs. dbinom(0,20,0.05) ≈ 0,358 — praktisch identisch.

Gegenprobe
Eine Lieferung von N = 100 Stück enthält M = 5 defekte. Du prüfst n = 20 ohne Zurücklegen. Welche R-Funktion zählt die Defekten?
  • dhyper(x, 5, 95, 20)
  • dbinom(x, 20, 0.05)
  • dpois(x, 1)
  • rbinom(20, 100, 0.05)
Richtig. Ziehen ohne Zurücklegen aus endlichem Los → hypergeometrisch: m = 5 (defekte), n = 95 (gute), k = 20 (Stichprobe).
Falsch. Ohne Zurücklegen aus einem endlichen Los → dhyper(x, m, n, k). Binomial wäre nur die Näherung, wenn n/N ≤ 5 %.

3. Poissonverteilung — „seltene Ereignisse pro Einheit"

Manchmal zählst du nicht geprüfte Stücke, sondern Ereignisse pro Zeit oder Fläche: Kratzer pro m², Anrufe pro Stunde, Ausfälle pro Woche. Die Ereignisse sind selten, unabhängig und im Durchschnitt kommt λ pro Einheit vor:

f(x) = e^(−λ) · λˣ / x!

Besonderheit: Erwartungswert und Varianz sind beide gleich λ. Es gibt keinen Parameter n — die Zahl der Möglichkeiten ist unbegrenzt.

# dpois(x, lambda): Kratzer pro m², im Schnitt 2
dpois(0, lambda = 2)               # P(0 Kratzer) ≈ 0,135
dpois(1, lambda = 2)               # P(1 Kratzer) ≈ 0,271
dpois(2, lambda = 2)               # P(2 Kratzer) ≈ 0,271
ppois(2, lambda = 2)               # P(X ≤ 2) ≈ 0,677
Output 
[1] 0.1353353
[1] 0.2706706
[1] 0.2706706
[1] 0.6766764
Binomial-Grenzfall

Wird n groß und p klein (seltene Ereignisse), läuft die Binomialverteilung in die Poissonverteilung mit λ = n·p über. Nimm die Annahmeprüfung mit n = 100, p = 0,02 (λ = 2):

P(X = x)BinomialPoisson (λ=2)
x = 00,1330,135
x = 10,2710,271
x = 20,2730,271

Beinahe gleich. Faustregel: Binomial als Poisson nähern, wenn n groß (≥ 20) und p klein (≤ 0,05) ist.

Verständnis
Warum eignet sich die Poissonverteilung für „Kratzer pro m² auf einer lackierten Fläche" besonders gut?
  • Weil Kratzer immer gleich verteilt sind
  • Weil die Fläche stetig gemessen wird
  • Weil es genau n Versuche gibt
  • Weil Ereignisse selten und unabhängig sind
Richtig. Seltene, unabhängige Ereignisse pro Fläche/Zeit — genau das Grundszenario von Poisson, gezählt statt geprüft, ohne festes n.
Falsch. Poisson passt, weil Kratzer selten und unabhängig sind. Ein festes n (Anzahl Versuche) ist das Binomial-Szenario.
R-Praxis
λ = 3 Ausfälle pro Woche. Welcher Wert ist qpois(0.95, lambda = 3)?
  • Die Wahrscheinlichkeit für 3 Ausfälle
  • Das 95 %-Quantil — Grenze der Ausfälle
  • Der Erwartungswert der Ausfälle
  • Die Dichte an der Stelle 3
Richtig. q = Umkehrung von F: die Zahl x, bei der P(X ≤ x) ≈ 0,95 erreicht wird — „in 95 % der Wochen fallen höchstens so viele aus".
Falsch. q liefert das Quantil (Grenzwert), nicht die Wahrscheinlichkeit (das wäre ppois) und nicht f(x) (das wäre dpois).

Vertiefung — was q bedeutet (am Würfel)

q ist die Umkehrung von p: p fragt „Wie viel Fläche liegt links von x?", q fragt „Bis wohin muss ich gehen, um diese Fläche zu erreichen?". Bei einer stetigen Verteilung ist die Antwort exakt (z. B. qnorm(0.975) = 1,96); bei einer diskreten ist es die erste ganze Zahl, die die Schwelle erreicht. Der Würfel aus L0003 macht das greifbar: Würfle 100-mal und zähle die Sechsen (X ~ Bin(100, 1/6)).

# q = Umkehrung von F: erste Zahl, die 95 % erreicht
qbinom(0.95, size = 100, prob = 1/6)  # 23
pbinom(22, size = 100, prob = 1/6)     # 0,937 — noch unter 0,95
pbinom(23, size = 100, prob = 1/6)     # 0,962 — Schwelle erreicht
Output 
[1] 23
[1] 0.9369497
[1] 0.9621356

„In 95 % der 100er-Würfe kommen höchstens 23 Sechsen" — das Quantil 23 ist die erste Zahl, bei der P(X ≤ x) ≥ 0,95 wird. Exakt wie bei qnorm, nur mit ganzzahligen Antworten. (Der faire Würfel ist übrigens ein Bernoulli-Experiment: „Sechs gewürfelt" = Erfolg mit p = 1/6 — damit ist qbinom das korrekte Würfel-Pendant zu qnorm.)

Didaktik — die Zieh-Metapher als Unterrichtsanker

Im Unterricht reicht ein einziger Entscheidungsbaum: „Ist die Menge endlich?" Ja → Hypergeometrisch. Nein (laufende Produktion) → Binomial. „Zähle ich Ereignisse statt Stücke?" → Poisson. Die Schüler müssen nicht Formeln memorieren, sondern die Geschichte des Ziehens erkennen — der Rest ist dbinom/dhyper/dpois.

Transfer
Ein Prüfstand zählt Brüche pro 1000 km einer Bauteilgruppe (im Schnitt 0,5). Welche Verteilung ist die richtige Wahl?
  • Poisson, λ = 0,5
  • Binomial, n = 1000
  • Hypergeometrisch, N = 1000
  • Stetig mit Dichte
Richtig. Seltene, unabhängige Ereignisse pro zurückgelegter Einheit → Poisson. Ein festes n gibt es hier nicht.
Falsch. Ereignisse pro Strecke = Poisson. n/p (Binomial) oder N/M/n (Hypergeometrisch) passen nur zum Stück-Prüfen.

Mitnehmen — der Kompakt-Kasten

BegriffEin Satz
Bernoulli-ExperimentEin Versuch mit zwei Ausgängen (i.O./defekt), Erfolgswsk p.
Binomial Bin(n, p)n unabhängige Versuche, konstantes p; f(x) = C(n,x)·pˣ·(1−p)ⁿ⁻ˣ; E = n·p.
HypergeometrischZiehen ohne Zurücklegen aus endlichem Los (N, M, n); exakt für ISO 2859; R: dhyper(x, M, N−M, n).
Poisson(λ)Seltene Ereignisse pro Zeit/Fläche; f(x) = e^(−λ)·λˣ/x!; E = Var = λ.
NäherungenHypergeo ≈ Binomial, wenn n/N ≤ 5 %. Binomial ≈ Poisson, wenn n groß, p ≤ 0,05 (λ = n·p).
R-Schemad = f(x), p = F(x), q = Quantil, r = Zufall — für alle drei identisch.

Hausübung (für dich — Selbststudium)

  1. Los N = 500, unbekannte Defektquote. Du prüfst n = 25 ohne Zurücklegen und findest x = 3 defekte. Berechne dhyper(3, 25, 475, 25) und vergleiche mit dbinom(3, 25, 0.05). Wie groß ist der Unterschied (n/N = 5 %)?
  2. Eine Maschine produziert Ausschuss mit p = 0,01. Berechne mit qbinom(0.90, 200, 0.01) die Grenze für 90 % der Lose (200 Stück). Was bedeutet der Wert in eigenen Worten?
  3. Poisson: Im Schnitt λ = 4 Fehler pro Bauteil. Wie groß ist die Wahrscheinlichkeit für höchstens 2 Fehler? (Tipp: ppois(2, 4) und die Summe von Hand gegenprüfen.)
  4. Entscheidungsfrage: „Prüfst du Stücke aus einer Lieferung" vs. „zählst du Ausfälle pro Woche" — welche Verteilung jeweils und warum?
  5. Begründe, warum die Hypergeometrische Verteilung die ehrlichere Rechnung für ISO-2859-Annahmeprüfung ist als die Binomialverteilung — und wann man die Binomialform trotzdem nutzen darf.
