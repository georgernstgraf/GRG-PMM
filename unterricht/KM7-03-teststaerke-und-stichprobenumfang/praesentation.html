KM7 · Wiederholung aus der 4. Klasse · Prozessmanagement

Teststärke

Der Fehler, den kein p-Wert zeigt —
und warum 4000 Teile auch nicht helfen.

5AHWIT · vor UE 1 (DoE) · 1. Doppelstunde
Lektüre

Navarro, Statistik für Human- und Sozialwissenschaftler (deutsch) — Kap. 13 (Teststärke beim t-Test) und Kap. 16 (Fehler 1. und 2. Art).

Voraussetzung: Lektion KM7-01 (t-Test) — alles rechnen wir am selben Test durch.

Einstiegsfrage

M1 gegen M2, 40 Messungen je Maschine,
10,0005 gegen 9,9769 mm. Ergebnis: p = 0,005456 — signifikant.

Die Frage, die kein p-Wert beantwortet:

Wie groß müsste der Unterschied sein, damit du ihn gar nicht gefunden hättest?

Mit 40 Teilen findest du fast alles. Mit 5 Teilen fast nichts.

Das Ziel: ein Aufruf, zwei Richtungen

# Richtung 1: wie sicher bin ich?
power.t.test(n = 40, delta = 0.0633, sd = 0.05, sig.level = 0.05)
# → power = 0.9999

# Richtung 2: wie viel brauche ich?
power.t.test(delta = 0.02, sd = 0.05, power = 0.8)
# → n = 99.08   →  rund 100 Teile je Maschine

Das rechnet man vor dem Versuch — nicht danach.

Schritt 1: die zwei Fehler

Test sagt „Unterschied"Test sagt „kein Unterschied"
H0 ist wahrFehler 2. Art (β)richtig
H0 ist falschrichtig (= 1 − α)Fehler 1. Art (α)

Fehler 1. Art — das Zuschauerurteil. Du findest einen Unterschied, den es nicht gibt. Dagegen schützt man sich mit α = 0,05.

Fehler 2. Art — das Blindeurteil. Du übersiehst einen echten Unterschied. Dagegen hilft α nichts — und es ist der teuerere Fehler.

Die Teststärke

Teststärke (Power) = 1 - β = P(echten Unterschied finden)

Der p-Wert sagt ausschließlich etwas über α aus. Über das Fehler-2-Art-Risiko sagt er nichts.

Schritt 2: Power mit unseren echten Daten

power.t.test(n = 40, delta = 0.0633, sd = 0.05)   # → 0.9999
power.t.test(n = 40, delta = 0.0238, sd = 0.036)   # → 0.8299

M1 gegen M3: Power praktisch 1 — 40 Messungen waren für 0,063 mm massiv überdimensioniert (n ≈ 12 reicht).

M1 gegen M2: 0,83. Der Test fand den Unterschied — und war keineswegs sicher, ihn zu finden.

Ein signifikantes Ergebnis fühlt sich genauso an wie ein nicht-signifikantes. Die Power ist die Angabe, die dazugehört.

Der gepaarte Vergleich zum Vergleich

power.t.test(n = 10, delta = 0.0633, sd = 0.05,
             type = "paired")
# → power = 0.9441

Nur 10 Paare — nicht 80 Einzelmessungen — und schon 94 % Power.

Der gepaarte Test ist rund viermal so effizient, weil die Rohcharge als Störgröße herausfällt. Das ist die Rechnung hinter der Entscheidung „gepaart oder ungepaart".

Schritt 3: die Frage vor dem Versuch

Gesucht ist das kleinste n mit Power ≥ 0,80 (σ = 0,05 mm):

sapply(c(0.10, 0.08, 0.06, 0.04, 0.02, 0.01),
       function(d) power.t.test(delta = d, sd = 0.05, power = 0.8)$n)

# →  5.09   7.23  11.94  25.52  99.08  393.41

0,06 mm → 12 Teile. 0,03 mm → 45. 0,01 mm → 393.

Die vierte Wurzel

n ∝ 1/δ²

Halbiert man den Effekt, braucht man viermal so viele Daten. Das ist der Grund, warum feine Effekte praktisch nie nachweisbar sind — und warum Versuchsplanung teuer ist.

Faustregel

Effekt halbieren → Daten vervierfachen. Effekt verdoppeln → Daten vierteln.

Schritt 4: warum 4000 Daten auch nicht helfen

sapply(c(50, 100, 200, 400, 1000, 4000), function(n) {
  power.t.test(n = n, delta = 0.02, sd = 0.05)$power })

# n=    50   100   200   400  1000  4000
# power 0.508 0.804 0.979 1.000 1.000 1.000

Bei n = 4000 ist die Power praktisch 1 — der 0,02-mm-Unterschied wird gefunden.

0,02 mm ist ein Zehntel der Toleranz von ± 0,15 mm. Der Test hätte einen vollkommen bedeutungslosen Effekt mit 4000 Teilen hochpräzise nachgewiesen — 40-mal mehr Prüfaufwand als nötig (für 80 % Power wären 100 gereicht).

Die Lehre

Signifikanz ist kein Gütebeweis.

Mit genügend Daten ist alles signifikant. Die p-Wert-Frage „Ist es signifikant?" führt in die Irre; die Power-Frage lautet: „Habe ich eine Aussage, die ich brauche?"

Merksatz

Zu jeder Testausgabe gehört die Power. Ein p-Wert allein ist eine unvollständige Information.

Schritt 5: der Anschluss an UE 1

Teststärken-PlanungVersuchsplanung (DoE)
Kleinster nachweisbarer EffektKleinster relevanter Effekt
Stichprobe n je MaschineAnzahl der Versuchsläufe
Streuung σVersuchsstreuung (Vorversuch)
Power ≥ 0,80Erkennbare Effektgröße im Modell

„Ein Versuch ohne Wiederholungen erkennt nichts" ist genau power.t.test(n = 1, …) — Power 0,000.

Jetzt du! (im Skript, Ctrl+Enter zeilenweise)

  1. Vorhersage zuerst: δ = 0,06 mm braucht n ≈ 12. Was passiert bei 0,12 und bei 0,03? Rechne beides nach.
  2. Power-Kurve für δ = 0,06 mm über n von 5 bis 40. Bei welchem n erreicht die Power 0,80 / 0,90 / 0,95?
  3. Toleranz ± 0,15 mm: Ist eine Drift von 0,02 mm ein Problem — und brauchst du dafür überhaupt einen Test?

Typische Fehler — vier Stück

# 1. Alle fuenf Argumente auf einmal
power.t.test(delta = 0.02, sd = 0.05, power = 0.8, sig.level = 0.05)
# ✗ exactly one of 'n','delta','sd','power','sig.level' must be NULL

# 2. sd beim gepaarten Test falsch verstanden
#    → muss die Streuung der DIFFERENZEN sein

# 3. Power nachher berechnen und schoenreden — wertlos

# 4. alpha = 0.05 als Power missverstanden ← haeufigster Irrtum
#    alpha sagt NICHTS darueber, wie oft ein Effekt gefunden wird

Zusammenfassung

KonzeptDas Wichtigste
Fehler 1. Art (α)Unterschied gefunden, den es nicht gibt
Fehler 2. Art (β)Echten Unterschied übersehen
Power = 1 − βP(echten Unterschied finden)

n ∝ 1/δ²Halber Effekt → viermal so viele Daten
