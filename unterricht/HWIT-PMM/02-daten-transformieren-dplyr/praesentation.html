Einstiegsfrage

Welche Pinguin-Art auf welcher Insel wiegt im Schnitt am meisten — und wie streut das Gewicht?

Vom letzten Plot zur Antwort: 344 Zeilen, 3 Arten, 3 Inseln. Die Antwort ist keine einzige Zahl — es ist eine Tabelle.

Genau für Tabellen-aus-Daten gibt es dplyr.

Das Ziel: eine Antwort-Tabelle

penguins |>
  group_by(species, island) |>
  summarise(
    n    = n(),
    gram = mean(body_mass_g, na.rm = TRUE),
    sd_g = sd(body_mass_g, na.rm = TRUE),
    .groups = "drop"
  )

Gentoo auf Biscoe: 5,1 kg — Kopf und Schulter über allen anderen. Heute bauen wir diese Pipe Zeile für Zeile.

Die Pipe |> — lesen wie einen Satz

# Ohne Pipe — von innen nach außen, rückwärts denken
summarise(
  filter(penguins, species == "Gentoo"),
  gram = mean(body_mass_g, na.rm = TRUE)
)

# Mit Pipe — von oben nach unten, wie ein Rezept
penguins |>
  filter(species == "Gentoo") |>
  summarise(gram = mean(body_mass_g, na.rm = TRUE))

|> reicht das linke Ergebnis als erstes Argument nach rechts. Eine Daten-Pipeline — Schritt für Schritt.

Die fünf dplyr-Verben

VerbMachtVorsicht
filter()Zeilen nach BedingungVerwechslungs-Klassiker mit select
select()Spalten auswählendito
mutate()neue Spalte berechnenüberschreibt gleiche Namen
arrange()Zeilen sortierendesc() für absteigend
summarise()zu einer Zeile zusammenfassenna.rm = TRUE!

Verben hängen an der Pipe — ein Verb pro Schritt, lesbar.

filter() & select() — die Unterscheidung

# Zeilen: nur Gentoo (Vergleich ==, nicht =)
penguins |> filter(species == "Gentoo")     # → 124 Zeilen

# Zeilen: Gentoo UND schwerer als 5 kg (Komma = und)
penguins |> filter(species == "Gentoo", body_mass_g > 5000)

# Spalten: nur das, was interessiert
penguins |> select(species, island, body_mass_g)
Der Klassiker

filter = Zeilen (logisch: behalten/weglassen) · select = Spalten (bilden: „wähle die Spalten"). Vertauschen ist der häufigste Fehler in dieser UE.

mutate() & arrange() — rechnen und ordnen

# Gramm → Kilogramm: neue Spalte, Einheiten sauber
penguins |>
  mutate(kg = body_mass_g / 1000) |>
  select(species, kg) |>
  head(3)

# Sortieren: die schwersten zuerst
penguins |>
  select(species, body_mass_g) |>
  arrange(desc(body_mass_g)) |>
  head(3)

mutate() behält alle Spalten und fügt eine hinzu — Rechenregeln gehören in eine Spalte, Klartext im Namen (kg, sd_g).

NA — fehlende Messwerte

NA = Not Available. Nicht Null, nicht leer — ein eigener Zustand.

x <- c(3750, 3800, NA, 3250)
mean(x)                # → NA!  (ansteckend)
mean(x, na.rm = TRUE)  # → 3600  (NA entfernt)
is.na(x)               # → FALSE FALSE TRUE FALSE
Wichtig

NA steckt jede Rechnung an. Die Pinguine haben echte NA — deshalb steht in unserer Zieltabelle überall na.rm = TRUE. Fragen aber zuerst: warum fehlt ein Wert?

group_by() + summarise() — die Antwort-Maschine

penguins |>
  group_by(species) |>
  summarise(
    n    = n(),
    gram = mean(body_mass_g, na.rm = TRUE),
    sd_g = sd(body_mass_g, na.rm = TRUE)
  )
speciesngramsd_g

Eine Gruppe = eine Zeile. n() zählt, mean()/sd() fassen zusammen. Genau das war unser Ziel-Artefakt.

Code-Stil — lesbar ist wartbar (Kap. 4)

# Guter Stil: snake_case, Leerzeichen, kurze Zeilen
body_mass_kg <- penguins |>   # Pipe am ZEILENENDE
  filter(species == "Gentoo") |>
  mutate(kg = body_mass_g / 1000)
RegelWarum
Namen: snake_casekeine Rätsel über Groß-/Kleinschreibung
Leerzeichen um Operatorenkg = g / 1000 statt kg=g/1000
|> ans Zeilenendeggplot-+-Regel — gleiche Logik

Stil ist kein Ästhetik-Thema: du liest deinen Code in drei Wochen wieder — schreibe für dieses Du.

Skripte & Projekte (Kap. 6)

Jede Woche ein RStudio-Projekt (eigenes Verzeichnis) — dann stimmen alle Pfade von selbst.

pmm-ue02/            # ein Ordner = ein Projekt
  pmm-ue02.Rproj     # File → New Project → New Directory
  analyse.R          # dein Skript
  messwerte.csv      # Daten liegen daneben
Faustregel

Projekt-Ordner = Wurzel. Relative Pfade ("messwerte.csv") statt absoluter ("C:/Users/…"). Dann läuft dein Skript auch auf dem Rechner der Kollegin.

Typische Fehler

# 1. = statt == beim filtern — Zuweisung statt Vergleich
penguins |> filter(species = "Gentoo")    # Fehler!

# 2. na.rm vergessen — eine Zahl raus, aber die falsche (NA)
penguins |> summarise(gram = mean(body_mass_g))   # → NA

# 3. group_by ohne summarise — biegt die Grafik verbogen
penguins |> group_by(species) |> ggplot(aes(x = body_mass_g)) +
  geom_histogram()     # Zeichnet VIEL zu viele kleine Grafiken!

Merksatz: = übergibt, == vergleicht.
