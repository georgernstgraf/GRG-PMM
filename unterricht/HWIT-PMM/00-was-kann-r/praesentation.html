Was kann R?

Vom Taschenrechner bis zur Prozessentscheidung —
in einer einzigen Sprache.

4HWIT · Wintersemester · Einstieg

1. R rechnet — sofort

2 + 2   # → 4: Eintippen, Ctrl+Enter, Antwort

mittel <- mean(c(10.01, 9.98, 10.03))
mittel   # → 10.007: <- speichert, Name holt zurück

Regel das ganze Semester: Code steht im Skript (Datei), nicht in der Konsole. Was du heute rechnest, läuft in einem Jahr noch genauso.

2. R liest Daten — echte Messwerte

library(tidyverse)

teile <- read_csv("../assets/betriebsdaten.csv")
glimpse(teile)   # → 120 Zeilen, 3 Spalten
SpalteBedeutung
maschineM1 / M2 / M3 — drei Fertigungsmaschinen
chargeChargen-Nummer (10 Chargen)
masse_mmGemessenes Maß, Soll 10,00 mm ± 0,15

120 Teile einlesen = eine Zeile. Bei 120.000 Teilen wäre es dieselbe Zeile.

3. R zeigt Daten — ein Bild statt 344 Zahlen

library(palmerpenguins)

ggplot(penguins,
       aes(x = flipper_length_mm, y = body_mass_g)) +
  geom_point()

Jeder Punkt = ein Pinguin (344 Messungen). Die Wolke wandert nach rechts oben: längere Flosse → schwererer Körper. Keine Formel nötig — die Antwort ist ein Bild.

Das ist UE 1: du baust genau dieses Bild heute selbst.

4. R rechnet mit Daten — Gruppen vergleichen

penguins |>
  group_by(species) |>
  summarise(mittel = mean(body_mass_g, na.rm = TRUE))
ArtMittlere MasseAnzahl
Adélie3701 g152
Chinstrap3733 g68
Gentoo5076 g124

Deutung in einem Satz: Gentoos sind im Schnitt über ein Kilo schwerer als die beiden anderen Arten. Lies die Pipe wie einen Satz: nimm → gruppiere → fasse zusammen.

5. R prüft — Zufall oder echter Unterschied?

t.test(body_mass_g ~ sex, data = penguins)

Ergebnis: p ≈ 5 · 10−16 — praktisch null. Männchen und Weibchen unterscheiden sich echt, das ist kein Messrauschen.

Ausblick KM 7: t-Test (UE 6), χ²-Test (UE 7), ANOVA (UE 8), Annahmestichprobenprüfung nach ISO 2859/3951 (UE 9–11) — alles derselbe Werkzeugkasten.
