Das Ziel: Lesen + Kennzahlen in einem Atemzug

library(tidyverse)
messwerte <- read_csv("messwerte.csv")   # 20 Zeilen, Sollwert 10,0

messwerte |>
  summarise(
    n     = n(),
    mitte = mean(mass_mm, na.rm = TRUE),
    mitte_med = median(mass_mm, na.rm = TRUE),
    streu = sd(mass_mm, na.rm = TRUE),
    iqr   = IQR(mass_mm, na.rm = TRUE)
  )

Und daneben: das Histogramm der Verteilung. Zahl + Bild zusammen — erst ab da reden wir seriös über einen Prozess.

Variation anschauen: das Histogramm

ggplot(messwerte, aes(x = mass_mm)) +
  geom_histogram(binwidth = 0.05, fill = "grey70", color = "white") +
  geom_vline(xintercept = 10, linetype = "dashed") +
  labs(x = "Maß (mm)", y = "Anzahl Teile",
       title = "Charge 47 — Sollwert 10,0 mm")

Der gestrichelte Strich = Sollwert. Das Auge sagt sofort: liegt der Prozess mittig? Wie viele Teile wandern nach rechts raus?

Mit binwidth experimentieren — die Bin-Größe steuert, wie grob du die Verteilung siehst.

Lagemaße — wo liegt die Verteilung?

MaßDefinitionIntuition
Mittelwert
mean(x)		 Summe / Anzahl Schwerpunkt — wo die Waage balanciert
Median
median(x)		 mittlerer Wert (sortiert) halbiert die Daten — 50% drüber, 50% darunter
Eselsbrücke: der Schwanz zieht den Mittelwert

Mittel ≈ Median → symmetrisch · Mittel > Median → rechtssteil (Schwanz rechts, z. B. Fertigungszeiten) · Mittel < Median → linkssteil.

Ausreißer — wem traut man?

19 Teile bei ~10,0 mm, ein Teil bei 10,8 mm (Verschub):

x <- c(rep(9.95, 4), rep(10.0, 8), rep(10.05, 7), 10.8)
mean(x)     # → 10.04  (verzerrt)
median(x)   # → 10.00  (unbeeindruckt)
Faustregel

Schiefe Verteilung / Ausreißer → Median. Symmetrisch und sauber → Mittelwert. Aber: erst gucken (Histogramm!), dann wählen.

Streuungsmaße — zwei Prozesse, gleicher Mittelwert

gruppe_a <- c(9.9, 9.95, 10.0, 10.05, 10.1)   # eng
gruppe_b <- c(9.5, 9.75, 10.0, 10.25, 10.5)   # weit
mean(gruppe_a); mean(gruppe_b)   # beide → 10
MaßIntuitionRobust?
Varianz var(x) mittlere quadrierte Abweichung (Einheit²)nein
Standardabweichung sd(x) √Varianz — „typische Entfernung vom Mittel"nein
IQR IQR(x) Q3 − Q1 — die mittlere 50%ja
Brücke zu KM 8

~68% aller Werte innerhalb ±1 sd, ~95% innerhalb ±2 sd (bei glockenförmiger Verteilung) — darauf bauen später die Regelkarten-Grenzen.

Typische Fehler

# 1. Text-Spalte, die Zahlen enthält (z. B. "10,05" — Komma!)
messwerte <- read_csv("messwerte.csv")   # mass_mm = chr statt dbl
# → zuerst glimpse(); R-Deckname: deutsches Excel-Komma

# 2. Binwidth schludrig — im Breitband sieht alles "normal" aus
geom_histogram()                     # Standard-Bins verzerren gern
geom_histogram(binwidth = 0.05)      # bewusst wählen, mehrfach testen

# 3. sd ohne na.rm — ein NA und die Streuung ist weg
summarise(streu = sd(mass_mm))       # → NA
