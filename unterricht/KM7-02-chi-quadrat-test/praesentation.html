Der Chi-Quadrat-Test

Passen die Häufigkeiten?
Zwei Testarten, ein Warnhinweis.

5AHWIT · vor UE 1 (DoE) · 1. Doppelstunde
Lektüre

Navarro, Statistik für Human- und Sozialwissenschaftler (deutsch) — Kap. 12, Chi-Quadrat-Tests (Pflicht).

Voraussetzung: Binomialverteilung (KM5-02) — der Anpassungstest ist genau ihre Anwendung.

Einstiegsfrage

in Toleranzaußerhalb
M1370
M2390
M3346

Hängt die Maschinenwahl damit zusammen, ob ein Teil in der Toleranz liegt?

6 Ausschusteile, und eine Maschine mit null. Sieht nach Zusammenhang aus. Aber: sieht aus reicht nicht.

Das Ziel

chisq.test(tab)
# → Pearson's Chi-squared test
#     X-squared = 12.022, df = 2, p-value = 0.002452

Der Test macht etwas sehr Einfaches: Er vergleicht jede beobachtete Häufigkeit mit der, die sich unter H0 ergeben müsste.

Schritt 1: die erwarteten Häufigkeiten

erwartet_ij = (Zeilensumme_i * Spaltensumme_j) / Gesamtsumme

Gesamtsumme: 116 gültige Messungen, davon 6 außerhalb.

M1 = 37 * 6 / 116 = 1.91
M2 = 39 * 6 / 116 = 2.02
M3 = 40 * 6 / 116 = 2.07
beobachteterwartet
M101,91
M202,02
M362,07

M3 hat fast dreimal so viele Ausschusteile wie ohne Zusammenhang zu erwarten. M1 und M2 haben null statt rund zwei.

Schritt 2: die Teststatistik

X² = Σ (Beobachtet - Erwartet)² / Erwartet

Quadriert, damit Plus und Minus sich nicht aufheben; durch die Erwartung geteilt, damit seltene Zellen mehr zählen.

M1:  (0 - 1.91)² / 1.91 = 1.91
M2:  (0 - 2.02)² / 2.02 = 2.02
M3:  (6 - 2.07)² / 2.07 = 7.47
   + Spalte "in Toleranz":  0.10 + 0.11 + 0.41

X² = 12,02

Der Name ist kein Geheimnis: es ist die Summe der quadrierten Abweichungen.

Den p-Wert richtig lesen

p = 0.0025 # 0,25 % aller Faelle, wenn es KEINEN Zusammenhang gibt

heißt: Wenn es keinen Zusammenhang gäbe, wäre eine so große Abweichung in 0,25 % aller Fälle zu sehen.

Der Zusammenhang ist da. H0 wird verworfen.

Nicht

0,25 % ist nicht die Wahrscheinlichkeit, dass der Zusammenhang falsch ist. Der p-Wert gehört immer zu den Daten, nicht zur Zukunft.

Die Freiheitsgrade

df = (Zeilen - 1) * (Spalten - 1) = (3 - 1) * (2 - 1) = 2

Nicht die Anzahl der Zellen, sondern wie viele Zellen man frei wählen kann, nachdem die Summen feststehen.

Die rechte Spalte ist keine echte Entscheidung — sie ergibt sich aus der linken. Daher df = 2, nicht 6.

Schritt 3: der Anpassungstest

Andere Frage: Stimmt die Verteilung mit einer Sollquote überein? Kunde: 10 % Ausschuss.

chisq.test(c(in_Toleranz = 34, ausserhalb = 6),
            p = c(0.9, 0.1))

# → X-squared = 1.1111, df = 1, p-value = 0.2918

Die 15 % Ausschussquote von M3 sind von den geforderten 10 % statistisch nicht unterscheidbar.

Genau das, was die Binomialverteilung aus KM5-02 vorhergesagt hat.

Die Falle: Abweichung in beide Richtungen

Dasselbe mit M1 — 0 Ausschusteile von 37:

chisq.test(c(in_Toleranz = 37, ausserhalb = 0),
            p = c(0.9, 0.1))

# → X-squared = 4.1111, df = 1, p-value = 0.0426

M1 hat keinen einzigen Ausschuss — und der Test meldet signifikante Abweichung. Erwartet waren 3,7.

Ein Anpassungstest ist kein Güteurteil, sondern ein Vergleichstest. Er erkennt jede Abweichung — in beide Richtungen.

Schritt 4: die Warnung, die R nicht unterschlägt

erwartet <- outer(rowSums(tab), colSums(tab)) / sum(tab)

# →   ausserhalb  in_Toleranz
#     M1          1.91        35.09
#     M2          2.02        36.98
#     M3          2.07        37.93

Regel: mindestens 80 % der erwarteten Häufigkeiten ≥ 5. Hier: 3 von 6 = 50 %.

Der Chi-Test nähert durch eine Normalverteilung — dafür sind zu wenige Daten da. 0,0025 ist eine Näherung, die nicht hält.

Die Alternative: der exakte Test

fisher.test(tab)
# → Fisher's Exact Test for Count Data
#     p-value = 0.003177

Rechnet ohne Näherung — kommt auf 0,0032. Praktisch dasselbe Urteil, aber ohne die Näherungsannahme.

Regel für die Praxis

Zu wenige Daten → fisher.test(). Viele Daten → chisq.test(). Und nie die Warnung ignorieren.

Schritt 5: der Datensatz

daten <- read_csv("../../assets/betriebsdaten.csv") |>
  mutate(iok = if_else(is.na(masse_mm), NA,
          if_else(abs(masse_mm - 10) > 0.15,
                  "ausserhalb", "in_Toleranz")))

table(daten$maschine, daten$iok)

#     ausserhalb  in_Toleranz
#   M1     0          37
#   M2     0          39
#   M3     6          34
Warum is.na() zuerst?

if_else() braucht für jeden Fall einen Wert. Ohne den NA-Zweig würden die vier fehlenden Messungen fälschlich als „in Toleranz" gezählt.

Jetzt du! (im Skript, Ctrl+Enter zeilenweise)

  1. Vorhersage zuerst: Welche Zelle trägt am meisten zur Teststatistik bei? Rechne den Beitrag von Hand nach und vergleiche mit R.
  2. Anpassungstests für alle drei Maschinen gegen 10 %. Welche fällt statistisch auf — und in welche Richtung?
  3. Berechne alle erwarteten Häufigkeiten. Welcher Anteil liegt unter 5, und welches Testverfahren folgt daraus?

Typische Fehler — vier Stück

# 1. Prozentzahlen statt Haeufigkeiten
chisq.test(c(0.90, 0.10))   # → sinnlos

# 2. correct = FALSE als schneller Fix
#    versteckt das Problem, behebt es nicht

# 3. Die Warnung ueberlesen
#    "approximation may be incorrect" ist der wichtigste Satz

# 4. chisq.test() fuer metrische Daten
#    der Test braucht KATEGORIEN — Mittelwerte: t-Test
