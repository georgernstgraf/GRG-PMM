Einstiegsfrage

Pinguine: Lange Flosse → schwerer Körper?
Wie würdest du das ohne eine einzige Formel beantworten?

Wir haben 344 gemessene Pinguine, 3 Arten, 11 Merkmale.

Zeichnen. Die Antwort ist ein Bild — und R kann es zeichnen.

Das Ziel: ein Bild, das die Frage beantwortet

library(tidyverse)
library(palmerpenguins)

ggplot(penguins,
       aes(x = flipper_length_mm, y = body_mass_g, color = species)) +
  geom_point() +
  labs(x = "Flossengröße (mm)", y = "Körpermasse (g)",
       title = "Lange Flosse, schwerer Körper")

Was das Bild zeigt: Jeder Punkt = ein Pinguin. Punkte wandern nach rechts oben — längere Flosse, höhere Masse. Drei Farbgruppen schichten sich sauber übereinander.

Heute bauen wir dieses Bild Schritt für Schritt auf.

Das Skelett: drei Bausteine

ggplot(penguins,
       aes(x = flipper_length_mm, y = body_mass_g))
BausteinWas er sagt
ggplot(penguins)mit welchen Daten
aes(x = …, y = …)welche Zuordnung (Mapping) — Spalte → Position
+ geom_…()wie gezeichnet wird

Führe es aus: Nur ein leeres Koordinatensystem erscheint. R kennt die Zuordnung — aber noch nicht, wie es zeichnen soll.

Schritt 2: sagen, wie gezeichnet wird

ggplot(penguins,
       aes(x = flipper_length_mm, y = body_mass_g)) +
  geom_point()

geom_point() = ein Punkt pro Beobachtung → Streudiagramm.

Der + kombiniert Schichten — wie eine Folge von „und dann …”. Und das Koordinatensystem ist da.

Schritt 3: Farbe als Information

ggplot(penguins,
       aes(x = flipper_length_mm, y = body_mass_g, color = species)) +
  geom_point() +
  labs(x = "Flossengröße (mm)", y = "Körpermasse (g)")

color = species — die Spalte species wird zur Farbe gemappt. Die Legende entsteht von allein, pro Art eine Farbe.

Das Prinzip

Werte aus den Daten → äußerliche Eigenschaft des Plot-Elements. color = species (Mapping, in aes()) ≠ color = "red" (Einstellung, in geom_…()).

Facetten — drei Bilder statt drei Farben

ggplot(penguins,
       aes(x = flipper_length_mm, y = body_mass_g)) +
  geom_point() +
  facet_wrap(~ species)

facet_wrap(~ species) = eine Mini-Grafik pro Art.

Faustregel: Farbe zum Vergleichen, Facetten zum Gegeneinanderstellen. Beides beantwortet unterschiedliche Fragen.

Die Gleitschicht: geom_smooth()

ggplot(penguins,
       aes(x = flipper_length_mm, y = body_mass_g, color = species)) +
  geom_point() +
  geom_smooth() +
  labs(x = "Flossengröße (mm)", y = "Körpermasse (g)")

geom_smooth() legt einen Trend-Schleier über die Punkte — für jede Art eine eigene Linie, weil color gemappt ist.

Alle drei Arten steigen: mehr Flosse, mehr Masse. Unsere Einstiegsfrage ist beantwortet — mit einem Bild statt einer Formel.

Andere Frage, anderer Geom

# Verteilung: Wie hoch wiegen die Pinguine?
ggplot(penguins, aes(x = body_mass_g)) +
  geom_histogram(binwidth = 250) +
  labs(x = "Körpermasse (g)", y = "Anzahl Pinguine")

# Kategorien: Wie viele pro Art?
ggplot(penguins, aes(x = species)) +
  geom_bar()

Ein Geom = eine Frage-Typ. Nicht das Werkzeug wählen und dann die Frage verbiegen — umgekehrt.

Workflow: Skript statt Konsole (Kap. 2)

RStudio: 4 Fenster. Oben links schreibt man das Skript, unten links antwortet die Konsole.

# Skript = dein Labortagebuch: lesbar, wiederholbar, startbar
gewicht <- c(3750, 3800, 3250)   # <- speichert (nicht = !)
mean(gewicht)                     # → 3600
RStudio-Shortcuts

Alt + - tippt <- · Ctrl + Enter führt die aktuelle Zeile aus · Ctrl + Shift + S startet das ganze Skript.

Konsole = Nachfragen. Skript = Nachvollziehen. Alles, was du heute tust, landet im Skript.

Jetzt du! (im Skript, Ctrl+Enter zeilenweise)

  1. Wie hoch wiegen Pinguine im Schnitt? Streudiagramm body_mass_g gegen bill_length_mm — was fällt dir auf?
  2. Färbe denselben Plot nach island. Welche Insel hat nur eine Art?
  3. Errate vorher, dann ausführen: ggplot(penguins, aes(x = species, y = body_mass_g)) + geom_point() — ist das lesbar? Was wäre besser? (Tipp: geom_boxplot())

Typische Fehler — heute schon garantiert

# 1. Das + am Zeilenanfang — R sucht vergeblich das Vorherige
ggplot(penguins, aes(x = body_mass_g))
  + geom_point()          # → Fehler! Plus gehört ans ZEILENENDE

# 2. aes vergessen — R weiß nicht, was wohin soll
ggplot(penguins) + geom_point(aes(y = body_mass_g))   # kein x → nichts zu sehen

# 3. Farbe festgenagelt statt gemappt
geom_point(color = "red")   # ALLE Punkte rot — keine Information, keine Legende
