R rechnet mit: was du vom Taschenrechner kennst

Mittelwert, Streuung und Verteilungen — dieselben Formeln, nur schneller und reproduzierbar.

Lektüre

Navarro, Learning Statistics with R (englisch) — lies Kap. 9 (Probability) und Kap. 10 (Estimating unknowns). Den Stoff kennst du aus KM5; hier siehst du, wie R ihn rechnet.

Einstiegsfrage

Mittelwert und Standardabweichung habt ihr bisher mit dem Taschenrechner gerechnet — für eine Handvoll Werte. Heute liegt eine Messreihe mit 342 Pinguin-Massen vor dir. Wie lange bräuchtest du dafür? Und wie wahrscheinlich ist es, dass ein Pinguin mehr als 5 kg auf die Waage bringt?

Die zweite Frage kann der Taschenrechner gar nicht beantworten. Genau dafür gibt es R.

Ziel-Artefakt

Zuerst die Kennzahlen — in einer Zeile statt in einer Stunde:

penguins |>
  summarise(
    n     = n(),
    mitte = mean(body_mass_g, na.rm = TRUE),
    streu = sd(body_mass_g, na.rm = TRUE)
  )
# → n: 342 · mitte: 4201.75 · streu: 801.95

Und dann die Frage von oben — mit einer Verteilungsfunktion:

pnorm(5000, mean = 4201.75, sd = 801.95)
# → 0.8402 — rund 84 % aller Pinguine bleiben unter 5 kg

Der Win von heute: Du weißt zu jeder Formel aus KM5 den passenden R-Befehl — und kannst Ergebnisse deuten, nicht nur ausrechnen.

Schritt 1 — Kennzahlen, die du kennst

Dieselben Formeln wie am Taschenrechner, jetzt auf alle 342 Werte zugleich:

penguins |>
  summarise(
    mitte   = mean(body_mass_g, na.rm = TRUE),
    median  = median(body_mass_g, na.rm = TRUE),
    streu   = sd(body_mass_g, na.rm = TRUE),
    varianz = var(body_mass_g, na.rm = TRUE),
    iqr     = IQR(body_mass_g, na.rm = TRUE)
  )
# → mitte 4201.75 · median 4050 · streu 801.95
#   varianz 643131.1 · iqr 1200

Zwei Dinge, die ihr in der Prüfung verwechselt habt, sind hier sichtbar: sd() ist die Standardabweichung, var() ist ihr Quadrat — die Varianz. Und R teilt bei sd()/var() durch n − 1 (Bessel-Korrektur), genau wie in der Formel für die Stichprobe.

sd(penguins$body_mass_g, na.rm = TRUE)^2
# → 643131.1 — die Varianz, wie erwartet

IQR(penguins$body_mass_g, na.rm = TRUE)
# → 1200 — das ist Q3 − Q1 (nicht Max − Min!)

Die Quartile selbst bekommst du mit quantile(): Q1 = 3550, Median = 4050, Q3 = 4750. Die mittleren 50 % der Pinguine wiegen also zwischen 3550 g und 4750 g.

Was berechnet var(penguins$body_mass_g, na.rm = TRUE)?

var() = σ², sd() = die Wurzel daraus. Ein Hinweis auf den Unterschied ist die Einheit: Varianz trägt g², Standardabweichung trägt g.

Schritt 2 — Schätzwert oder Parameter?

Die 342 Pinguine sind eine Stichprobe. Was R dir ausgibt, sind Schätzwerte (x̄ und s) für die wahren Parameter der Grundgesamtheit (μ und σ). Gruppieren wir nach Art — dann wird der Unterschied greifbar:

penguins |>
  group_by(species) |>
  summarise(
    mitte = mean(body_mass_g, na.rm = TRUE),
    streu = sd(body_mass_g, na.rm = TRUE)
  )
# → Adelie 3701 / 459   Chinstrap 3733 / 384   Gentoo 5076 / 504

Gentoo ist im Mittel fast 1,4 kg schwerer als Adelie — und streut auch breiter. Ob dieser Unterschied bedeutsam oder nur Zufall der Stichprobe ist, klären wir ab UE 6 mit Tests.

Mittelwert x̄ und Streuung s aus summarise() sind …

x̄ und s sind Stichprobenkennzahlen — Punktschätzungen für μ und σ. Jede andere Stichprobe hätte etwas andere Werte ergeben.

Schritt 3 — stetig oder kategorial?

Das richtige Diagramm hängt am Merkmalstyp. Die Masse ist stetig → Histogramm (englisch: histogram):

ggplot(penguins, aes(x = body_mass_g)) +
  geom_histogram(binwidth = 250, color = "white")
# → eine Glocke: die meisten Massen zwischen 3500 und 5000 g

Die Art ist kategorial → Balkendiagramm (englisch: bar chart):

ggplot(penguins, aes(x = species)) +
  geom_bar()
# → drei Balken: Adelie 152 · Gentoo 124 · Chinstrap 68

Ein Histogramm auf species ist ein Klassiker-Fehler — es funktioniert hier schlicht nicht (siehe unten).

Welches Geom zeichnet die Häufigkeiten der kategorialen Spalte species?

geom_histogram() braucht ein stetiges x für die Bins. Für Kategorien zählt geom_bar() die Häufigkeiten je Ausprägung.

Schritt 4 — Die d/p/q/r-Familie

Zu jeder Verteilung aus KM5 gibt es vier R-Funktionen. Das Muster ist immer dasselbe — merke dir die vier Buchstaben:

FunktionBedeutungFrage an R
d…densityWie hoch ist die Dichte bei x? (diskret: P(X = x))
p…probabilityWie groß ist P(X ≤ x)? (die Fläche links)
q…quantileWelches x hat P(X ≤ x) = p? (die Umkehrung)
r…randomn Zufallszahlen aus dieser Verteilung

Für die Normalverteilung hängen die Buchstaben an norm:

pnorm(5000, mean = 4201.75, sd = 801.95)
# → 0.8402 — P(Masse ≤ 5000 g)

pnorm(1) - pnorm(-1)
# → 0.6827 — rund 68 % im Bereich μ ± 1σ

pnorm(2) - pnorm(-2)
# → 0.9545 — rund 95 % im Bereich μ ± 2σ

qnorm(0.975)
# → 1.96 — der z-Wert für das 95 %-Intervall (kommt in UE 5)

Für diskrete Verteilungen steht hinter dem Buchstaben die Verteilung: binom, pois, exp …

dbinom(2, size = 10, prob = 0.3)
# → 0.2335 — P(X = 2) bei B(10; 0,3)

pbinom(2, size = 10, prob = 0.3)
# → 0.3828 — P(X ≤ 2), also 0 + 1 + 2 Treffer zusammen

dpois(2, lambda = 3)
# → 0.2240 — P(X = 2) bei Poisson mit λ = 3

pbinom(2, size = 10, prob = 0.3) liefert 0.3828. Was bedeutet das?

p = kumulativ (P(X ≤ x)). Genau zwei Treffer wären dbinom(2, …) = 0.2335 — der Unterschied d gegen p.

Schritt 5 — Verteilung sehen: Boxplot und QQ-Plot

Der Boxplot zeigt Median, Q1/Q3 und Ausreißer — nicht den Mittelwert. Die Whisker reichen bis 1,5·IQR, alles darüber wird als einzelner Punkt gezeichnet:

ggplot(penguins, aes(x = species, y = body_mass_g)) +
  geom_boxplot()
# → drei Boxen; Gentoo deutlich schwerer; Punkte = Ausreißer

Und ob die Normalverteilung eine brauchbare Näherung ist, prüft der QQ-Plot — bei gutem Fit liegen die Punkte auf der Geraden:

ggplot(penguins, aes(sample = body_mass_g)) +
  stat_qq() +
  stat_qq_line()
# → Punkte folgen grob der Geraden (Ränder leicht daneben)

Typische Fehler

Ohne na.rm = TRUE wird alles NA

mean(penguins$body_mass_g)
# ✗ NA — zwei fehlende Werte „infizieren" den Mittelwert

R weigert sich, über fehlende Werte hinwegzumitteln, ohne dass du es erlaubst: na.rm = TRUE ist die Erlaubnis.

Varianz und Standardabweichung verwechselt

var(penguins$body_mass_g, na.rm = TRUE)
# → 643131.1 — das ist σ², die Einheit wäre g², nicht g

Wer die Varianz als „Streuung" berichtet, hat die Einheit verloren. Für Aussagen in Gramm ist sd() zuständig.

Histogramm auf einem kategorialen Merkmal

ggplot(penguins, aes(x = species)) +
  geom_histogram()
# ✗ "stat_bin() requires a continuous x aesthetic"

Die Fehlermeldung sagt genau, was fehlt: ein stetiges x. Nimm geom_bar().

d und p vertauscht

dbinom(2, 10, 0.3)   # P(X = 2) — genau zwei Treffer
pbinom(2, 10, 0.3)   # P(X ≤ 2) — höchstens zwei Treffer

Merke: d = ein Wert, p = kumulierte Fläche bis zu diesem Wert.
